# 1. TUJUAN DOKUMEN

Dokumen ini digunakan untuk mencatat prompt yang digunakan selama proses perancangan dan pengembangan Sistem Monitoring Minat Belajar Siswa SD Berbasis Web.

Prompt log digunakan untuk:

- Mendokumentasikan proses penggunaan AI selama pengembangan.
- Menjelaskan tujuan dari setiap prompt.
- Mencatat hasil yang diperoleh dari prompt.
- Menjaga keterlacakan antara kebutuhan sistem dan hasil pengembangan.
- Membantu evaluasi apabila terdapat perubahan kebutuhan sistem.
